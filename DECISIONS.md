| 2026-11-05 | Core mechanics: a maze world; lives measured in steps; a goal across the map that brings a life bonus and an offspring; roaming threats that drain life on contact; information shared only at home; stings that take half of a bee's life, with one heal per life at home; hornets drawn to bees in proportion to their life; a colony size cap; seasons with different challenges; two sounds heard within 10 steps; a map 3 to 5 times larger | Jacob Schoenberg | | Jacob's design |

| 2026-11-06 | Hornets do not pursue a bee they stung while the 10-tick sting cooldown runs | Agent proposal (Claude Code, phase 1 build); awaiting Jacob | Leave chasing as is; make stings end the chase permanently | Hornets move at bee speed, so a hornet followed its victim and stung it every 10 ticks until it died, the lock the cooldown was meant to prevent. This keeps the cooldown's purpose and gives the smell gene a role (a long-range hornet can find the bee again). |
| 2026-11-06 | Hornets move on 80% of ticks (`hornet_speed` 0.8) | Agent proposal (Claude Code, phase 1 build); awaiting Jacob | Equal speed | At equal speed a fleeing bee can never gain distance, so `flee` could not work. |
| 2026-11-06 | Ambush timing: a free hornet heads for an ambush spot (an earlier sting spot or a bloom cell) with probability 0.02 x ambush/10 per tick and waits 4 x ambush ticks there | Agent proposal (Claude Code, phase 1 build); awaiting Jacob | Roll the ambush gene every tick (first build) | Rolling every tick sent every hornet to camp on the bloom, so even oracle bees rarely delivered. The spec gives no numbers for this gene. |
| 2026-11-06 | Base life L = 500 (spec start value 250), `min_bloom_distance` 55, maze `openness` 0.15 | Agent proposal from the setup calibration (EXPERIMENTS.md, "Setup calibration"); awaiting Jacob | L 250 or 400; distance 65; openness 0.25 | At this point oracle bees deliver on 0.708 of spring trips, rule bees 0.024, random bees 0 (3 seeds each), which meets the calibration target. |
| 2026-11-06 | Smaller interpretations of the spec: bees inside the hive (entrances included) cannot be stung; `explore` falls back to a frontier within 90 degrees when none lies within 50; the 50% and 25% life triggers are fractions of base life L; bloom patches lie between the minimum distance and 1.5 times it; the calibration-only oracle flees hornets within 3 cells | Agent proposals (Claude Code, phase 1 build); awaiting Jacob | See docs/BUILD_NOTES.md, "Changes from the spec" | Each fills a gap the spec leaves open, or fixes a behaviour that stalled scripted bees in the maze. |
| 2026-11-06 | What `no_memory` removes: the last-8 events, notes (`remember`, also dropped from the schema), recall, remembered bright spots and moving things, and the explored share. It keeps the present: what happened and what was said at home since the bee last decided, its current intent and where home is. `no_talk` drops `say` from the schema and the system prompt | Agent proposal (Claude Code, phase 2 build); awaiting Jacob | Drop heard-at-home talk too under `no_memory` | Dropping talk would make `no_memory` also a `no_talk` arm, so E1 could not tell the two ablations apart. |
| 2026-11-06 | Memory details the spec left open: talk heard at home is also stored as an episode (importance 2), so recall can bring back talk older than the last 6 lines; touching bloom counts as "bloom seen" (4); all notes (up to 12) are shown at every decision, and recall (top 6) ranks episodes only, scoring recency (0.99 per tick) + importance/5 + BM25 relevance (normalised to the best match), with coarse 8 x 8 regions as place tokens | Agent proposal (Claude Code, phase 2 build); awaiting Jacob | Recall over notes and episodes together; no talk in episodes | Notes are few and short, so showing them all costs little; talk in episodes is what can carry knowledge past the 6-line window. |
| 2026-11-06 | Neutral wording of experiences: a sting is "lost half your life in an instant", with no cause named; a delivery is "your life rose"; other members are `m` in the view (the sim marks them `b`) | Agent proposal (Claude Code, phase 2 build); awaiting Jacob | Name the cause ("a moving thing took half your life") | Naming the cause would hand the model the link between moving things and life loss, which is one of the things we want to see it work out. |
| 2026-11-06 | Model failures: an API error is retried twice (1 s, 2 s), then the bee waits and a `mind_error` event is logged; a refusal or malformed reply also gives `wait` and `mind_error`; a replay cache miss or the budget cap stops the run | Agent proposal (Claude Code, phase 2 build); awaiting Jacob | Retry forever; drop the bee's turn silently | Silent gaps would bias results; a stopped run cannot be mistaken for a complete one. |
| 2026-11-06 | `stop_after` run length for pilot runs (the pilot is the first full-size spring) | Agent proposal (Claude Code, phase 2 build); awaiting Jacob | A smaller pilot world | The pilot should test the world the main runs use. The world rules are unchanged. |
| 2026-11-06 | Secret scan: an assigned value ends at a backslash | Agent fix (Claude Code, phase 2 build) | Add the false hit to the redaction list | Exported traces are JSON, where newlines are written `\n`; the scanner read code like `cache_creation_input_tokens=0))\nreturn` as one secret-looking value. A test checks a real-looking key in escaped JSON is still caught. |
| 2026-11-06 | Run each AI arm as its own process from a clean git worktree at the run commit (9cb4e7a), each with its own replay-cache folder and spend ledger; five processes at once rather than three or four | Agent decision (Claude Code, phase 4), within the setup prompt's instructions except the process count; awaiting Jacob | Run from the main checkout; four processes | Later commits during the runs could not change a running experiment or its provenance. Separate ledgers avoid lost updates when processes write the same file. With four processes one arm would have waited for another, roughly doubling the run time; five kept concurrent model calls far below the 40 tested without errors. |
| 2026-11-06 | Extend `full` and `no_talk` to seeds 3 and 4 (pre-registration amendment 1) | Agent decision (Claude Code, phase 4) under the pre-registration's "budget allowing" clause; awaiting Jacob | Stay at 3 seeds | A run cost about $0.37, so 4 more runs cost little; the extension was started before seeds 1 and 2 had finished and runs whatever the outcome. |
| 2026-11-06 | Pack each run's replay-cache entries into one gzip file (`tools/pack_llm_cache.py`), and have `llm.py` read packs in auto and replay mode | Agent proposal (Claude Code, phase 4), as the setup prompt asked | Commit loose entries; compress each entry in place | About 0.45 KB a call against 7 KB loose (the pilot's 355 calls: 0.16 MB packed), so every main run's responses fit in the repository. |
